## Deviations / defaults (owner unknowns)
1. **Sentry and the Google Drive upload are not built** (Ratna, 2026-09-26: not required for now). The interim off-server copy is an encrypted 30-day GitHub artifact; it does not survive losing the GitHub account. The runbook says what each later step needs.
2. The spec says weekly dump in one place and daily in another; built **daily**, as the topology table says.
3. The spec's "Playwright smoke" is a fetch-based HTTP smoke plus one browser visit to the sign-in page. A signed-in browser smoke needs an emailed code and an authenticator secret in CI; not attempted.
4. The restore drill loads data into a database built from the migrations (data-only dump), so a backup must be restored with the checkout at its own migration version; the drill refuses a mismatch. A full-schema dump would avoid that but cannot restore into Supabase-managed schemas cleanly.
5. The bundle scan reads `.next/static` (what the browser downloads), not the server output.
6. `supabase db push` approval workflow, Vercel preview safety (`preview_reader`), log drain and Vercel alerts are go-live work (change 17).
